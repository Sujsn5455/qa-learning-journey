\# Day 1 — QA vs QC vs Software Tester



\## QA (Quality Assurance)

QA is process-focused and proactive. It prevents defects before they happen by ensuring the development process follows proper standards, procedures, and best practices.



Key idea: Are we building the project the right way?



QA focuses on:

\- Process and procedures

\- Development standards

\- Best practices

\- Preventing defects

\- Continuous improvement



QA is proactive and prevention-oriented.



Example: Writing a test plan for Salon booking features before development starts.



\---



\## QC (Quality Control)

QC is product-focused and reactive. It identifies defects in the actual product through testing, inspection, validation, and verification.



Key idea: Did we build the project right?



QC focuses on:

\- Testing

\- Inspection

\- Verification

\- Finding defects

\- Logging bugs

\- Running test cases



QC is reactive and detection-oriented.



Example: Running login test cases on the Salon system and reporting bugs.



\---



\## Software Tester

A Software Tester is the person who executes QC activities. The tester writes and runs test cases, finds bugs, and reports them.



Example: Me, testing the Salon booking flow.



\---



\## Quick Comparison



| QA | QC |

|----|----|

| Quality Assurance | Quality Control |

| Process-focused | Product-focused |

| Proactive | Reactive |

| Prevents defects | Detects defects |

| Asks: Are we building it right? | Asks: Did we build it right? |

| Standards and procedures | Testing and inspection |



\---



\## Easy Way to Remember



QA = Process → Prevent → Proactive

QC = Product → Detect → Reactive

Tester = Person who executes QC



\---



\## Salon Booking System — Real Examples



\### QA Activities (Prevent)

\- Writing test plan for booking features

\- Reviewing requirements for booking time slots

\- Defining coding standards

\- Setting up Git branching rules

\- Creating a validation checklist



\### QC Activities (Detect)

\- Running login test cases on Salon system

\- Testing booking time slot selection

\- Reporting a bug where customer name shows blank

\- Checking appointment confirmation email

\- Verifying database records after booking



\### Tester Role

\- Me, executing all QC activities

\- Reporting bugs to development team

\- Maintaining test cases and bug reports



\---



\## One-Line Summary



QA prevents defects by improving the process, while QC detects defects by testing and inspecting the product.
