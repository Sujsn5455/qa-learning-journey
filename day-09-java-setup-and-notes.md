\## What is Java?

Java is a programming language used for automation testing. It is platform-independent (write once, run anywhere).



\## Why Java for QA?

\- Used by REST Assured for API testing

\- Used by Playwright for browser automation

\- Used by TestNG and Maven for test frameworks

\- Most in-demand language for QA automation jobs
