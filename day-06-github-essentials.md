\# Day 6 — GitHub Essentials



\## What is README?

A README is a Markdown file that introduces a project. It appears on the repository home page.



\## Why README Matters

\- First thing recruiters see

\- Explains the project

\- Shows professionalism

\- 30 seconds to impress



\## What a Good README Contains

1\. Project title

2\. Short description

3\. Technologies used

4\. Features

5\. Setup instructions

6\. How to run tests

7\. Author info

8\. Screenshots or demo



\## What is a Pull Request (PR)?

A PR is a request to merge changes from one branch into another.

Flow:

1\. Create branch

2\. Make changes

3\. Open PR

4\. Reviewer approves

5\. Merge into main



\## What is an Issue?

An Issue tracks bugs, feature requests, or tasks.

\- Title

\- Description

\- Labels (bug, enhancement, question)

\- Assignee

\- Comments



\## GitHub Profile README

\## Markdown Basics

\- # Heading 1

\- ## Heading 2

\- \*\*bold\*\*

\- \*italic\*

\- - bullet list

\- 1. numbered list

\- \[link text](url)

\- `code`

\- ```code block```



\## Key Takeaway

A professional README + profile README + clean commits = strong GitHub presence. This is what recruiters see before they meet you.
