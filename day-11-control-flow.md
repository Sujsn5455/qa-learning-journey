# Day 11 — Control Flow in Java

## 1. if / else if / else
Makes decisions based on conditions.

## 2. switch
Selects one option from many.

## 3. for loop
Repeats a known number of times.

## 4. while loop
Repeats while condition is true.

## 5. do-while loop
Runs at least once, then checks condition.

## 6. break and continue
- break: exits the loop
- continue: skips current iteration

## QA Applications
- if/else: check pass/fail
- switch: select browser or environment
- for: run many test cases
- while: retry logic
- break/continue: control test flow

## Key Takeaway
Control flow lets code make decisions and repeat actions.
